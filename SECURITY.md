# Security policy

If you believe you have found a security or privacy vulnerability in Aside, please report it privately to **asidehelp@nickspeelman.com**.

Please do not open a public issue for an undisclosed vulnerability. Include the Aside version, Android version/device information when relevant, a clear description of the problem, and reproduction steps if you have them.

Do **not** send journal entries, backups, exported reports, screenshots containing private journal content, or other sensitive personal data unless it is truly necessary to explain the issue. If sensitive material is necessary, say so first and we can work out the safest way to proceed.

Aside is currently alpha software. Reports are reviewed on a best-effort basis; there is no formal bug-bounty program or response-time guarantee.
